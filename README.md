# Kreeda-Prerana Scout

AI-Powered Sports Talent Tracker Android Application

## 📌 Project Overview

Kreeda-Prerana Scout is an Android application developed to identify, track, and manage sports talent using AI-powered analytics and performance monitoring. The application helps coaches, teachers, and sports organizations analyze athlete performance, maintain records, and generate leaderboards for better talent identification.

The app is developed using modern Android development technologies including Kotlin, Jetpack Compose, MVVM Architecture, Room Database, and Repository Pattern.

---

## 🚀 Features

* Athlete Registration and Management
* Sports Category Selection
* Performance Tracking
* AI-Based Talent Analysis
* Leaderboard Generation
* Trial Logging System
* Data Storage using Room Database
* Modern UI using Jetpack Compose
* MVVM Architecture Implementation
* Repository Layer for Data Handling

↓

↓
